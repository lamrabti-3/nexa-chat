# NEXA — مساعدي الشخصي

NEXA تطبيق مساعد شخصي عربي بواجهة RTL، ذاكرة يختارها المستخدم، ومصادر مختارة عن التخصيص وعلم النفس السلوكي.

## ما الذي يقدمه؟

- محادثة خاصة بالعربية مع واجهة متجاوبة.
- موافقة واضحة قبل بدء المحادثة.
- ذاكرة صريحة: لا تُحفظ المعلومة إلا عندما يضغط المستخدم على حفظ.
- حذف أي ذكرى في أي وقت.
- تحليل وصفي حذر للتفضيلات، وليس تشخيصًا نفسيًا.
- مصادر مرفقة من NIST وAPA حول الخصوصية والدافعية ونماذج الشخصية.
- وضع محلي يعمل دون مفتاح API، حتى يمكن تجربة الواجهة بأمان.
- دعم أي خدمة متوافقة مع OpenAI Chat Completions عبر متغيرات بيئية.

## التشغيل محليًا

يتطلب Python 3.10 أو أحدث:

    python3 app.py

ثم افتح http://localhost:8080.

## تشغيل الذكاء الاصطناعي

الوضع المحلي لا يحتاج مفاتيح. للحصول على ردود نموذج لغوي كاملة، أضف الأسرار من إعدادات بيئة التشغيل، ولا تضعها داخل GitHub:

- AI_API_KEY — مفتاح مزود الخدمة.
- AI_API_URL — اختياري، افتراضيًا https://api.openai.com/v1/chat/completions.
- AI_MODEL — اختياري، افتراضيًا gpt-4o-mini.

مثال:

    AI_API_KEY=your-secret-key AI_MODEL=gpt-4o-mini python3 app.py

لا تحفظ nexa.db أو السجلات في Git؛ ملف .gitignore يحميها من الإضافات الجديدة.

## نموذج الذاكرة

NEXA لا يتعلم من كل رسالة تلقائيًا. يتعلم فقط من التفضيلات التي يختار المستخدم حفظها، مثل أسلوب الرد أو هدف شخصي. لا تستخدم الذاكرة لاستنتاج الصحة أو الدين أو السياسة أو الأصل أو أي سمة حساسة.

## ملاحظات السلامة

المساعد ليس طبيبًا أو محاميًا أو مستشارًا ماليًا. تحليل الشخصية احتمالي وقابل للتصحيح، والمصادر التعليمية لا تحوّل التطبيق إلى أداة تشخيص. راجع شروط الاستخدام وسياسة الخصوصية مع مختص قانوني قبل النشر العام.
