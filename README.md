# رَفيق — مساعدي الشخصي

رَفيق تطبيق مساعد شخصي عربي بواجهة RTL، ذاكرة يختارها المستخدم، وإعدادات تجعل طريقة الرد مناسبة لك.

## المزايا

- محادثة عربية متجاوبة للهاتف والكمبيوتر.
- موافقة واضحة قبل أول استخدام.
- ذاكرة صريحة: لا تُحفظ معلومة إلا باختيار المستخدم.
- تحليل وصفي حذر للتفضيلات، وليس تشخيصًا نفسيًا.
- إعداد الاسم والنبرة والهدف.
- تصدير البيانات بصيغة JSON ومسح المحادثة من داخل التطبيق.
- حماية اختيارية برمز وصول خاص.
- وضع محلي يعمل دون مفتاح AI.
- دعم أي خدمة متوافقة مع OpenAI Chat Completions.
- مصادر مختارة من NIST وAPA عن الخصوصية والدافعية ونماذج الشخصية.

## التشغيل

يتطلب Python 3.10 أو أحدث:

    python3 app.py

ثم افتح http://localhost:8080.

## تفعيل نموذج الذكاء الاصطناعي

أضف الأسرار من إعدادات بيئة التشغيل، ولا تضعها في GitHub:

- AI_API_KEY — مفتاح مزود AI.
- AI_API_URL — اختياري، افتراضيًا https://api.openai.com/v1/chat/completions.
- AI_MODEL — اختياري، افتراضيًا gpt-4o-mini.

بدون المفتاح يعمل رَفيق في الوضع المحلي التجريبي.

## حماية التطبيق

لجعل التطبيق خاصًا بك عند نشره، أضف:

- RAFIQ_ACCESS_CODE — رمز وصول طويل وغير سهل التخمين.

عند تفعيل الرمز تظهر شاشة دخول، وتُحمى واجهات المحادثة والذاكرة والتصدير. لا تشارك الرمز ولا تضعه داخل الملفات.

## البيانات والخصوصية

تُحفظ البيانات في SQLite محليًا في nexa.db عند التشغيل. هذا الملف والسجلات وملفات Python المؤقتة مستبعدة من Git عبر .gitignore. لا يحفظ رَفيق الذكريات تلقائيًا، ولا يستخدمها لاستنتاج الصحة أو الدين أو السياسة أو الأصل أو أي سمة حساسة.

## حدود الاستخدام

رَفيق ليس طبيبًا أو محاميًا أو مستشارًا ماليًا. الردود الآلية قد تخطئ، وتحليل الشخصية احتمالي وقابل للتصحيح. راجع شروط الاستخدام وسياسة الخصوصية مع مختص قانوني قبل النشر العام.
